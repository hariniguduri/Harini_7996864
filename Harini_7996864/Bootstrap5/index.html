19. Customization with Sass

Exercise 19.1

Bootstrap installed using npm:

npm init -y
npm install bootstrap
npm install sass --save-dev
Exercise 19.2

Customized Bootstrap variables using Sass:

_variables.scss

$primary: orange;
$border-radius: 1rem;
  
custom.scss

@import "variables";
@import "../node_modules/bootstrap/scss/bootstrap";

Recompiled Bootstrap using:

npx sass scss/custom.scss css/custom.css
